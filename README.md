<h1 align="center">JuceTidy</h1>


A [Clang-Tidy](https://clang.llvm.org/extra/clang-tidy/) plugin that adds [JUCE](https://juce.com)-specific checks.

The checks are largely based on the [JUCE Coding Standards](https://juce.com/discover/stories/coding-standards), as well as general advice and best-practices. Some are more opinionated than others but you can exclude any in your config that you don't wish to enforce.

## Checks

See [docs/checks.md](./docs/checks.md) for the full list of checks added by JuceTidy with explanations and justifications for each.

Each of the snippets below are valid C++ code that would compile and could be shipped, but each contain subtle bugs or bad practices. The warnings generated by JuceTidy are shown below each snippet.

### [`juce-realtime-safety`](docs/checks.md#juce-realtime-safety)

Warns about common realtime violations such as allocations, locks, or message-thread calls.

_`juce-realtime-safety` follows calls from audio callbacks into any function defined in the file currently being checked or headers included by that file. It can't see into functions defined in other `.cpp` files, or tell which override a virtual call will reach._

_Mark those functions `[[clang::nonblocking]]` to allow Clang-Tidy to properly follow the calls. See [docs/checks.md](./docs/checks.md#code-in-other-files)._

```cpp
void PluginProcessor::processBlock(juce::AudioBuffer<float>& buffer,
                                   juce::MidiBuffer&) override
{
    const juce::ScopedLock lock(stateLock);                     // [1]
    DBG("Processing " << buffer.getNumSamples() << " samples"); // [2]

    const auto cutoff = apvts.getRawParameterValue("cutoff")->load(); // [3]
    lowPass.process(buffer, cutoff);
}

void Lowpass::process(juce::AudioBuffer<float>& buffer, float cutoff)
{
    if (cutoff != lastCutoff)
        updateCoefficients(cutoff);
}

void Lowpass::updateCoefficients(float cutoff)
{
    filter.coefficients = juce::dsp::IIR::Coefficients<float>::makeLowPass(sampleRate, cutoff); // [4]
    lastCutoff = cutoff;
}
```

```text
[1] warning: constructing 'juce::GenericScopedLock' may block. Don't use it in the real-time audio callback 'processBlock' [juce-realtime-safety]
[2] warning: 'DBG' performs I/O and allocates memory. Don't use it in the real-time audio callback 'processBlock' [juce-realtime-safety]
[3] warning: calling 'juce::AudioProcessorValueTreeState::getRawParameterValue' looks up the parameter by its ID on every call. Don't use it in the real-time audio callback 'processBlock' [juce-realtime-safety]
[4] warning: calling 'juce::dsp::IIR::Coefficients::makeLowPass' allocates memory. Don't use it in 'LowPass::updateCoefficients', which is called from the real-time audio callback 'processBlock' [juce-realtime-safety]
```

### [`juce-attachment-order`](docs/checks.md#juce-attachment-order)

Warns when a component attachment will be destroyed after the component it's attached to.

```cpp
class Editor : public juce::AudioProcessorEditor
{
public:
    Editor(juce::AudioProcessor& p,
           juce::AudioProcessorValueTreeState& apvts)
        : juce::AudioProcessorEditor{ p }
        , gainAttachment{ apvts, "gain", gainSlider }
    {
    }

private:
    juce::AudioProcessorValueTreeState::SliderAttachment gainAttachment;
    juce::Slider gainSlider;
};
```

```text
warning: 'gainAttachment' is declared before 'gainSlider' which it's attached to. Declare 'gainAttachment' after 'gainSlider' [juce-attachment-order]
```

### [`juce-unknown-parameter-id`](docs/checks.md#juce-unknown-parameter-id)

Warns when you try to access a parameter that doesn't exist.

```cpp
juce::AudioProcessorValueTreeState::ParameterLayout createParameterLayout()
{
    return {
        std::make_unique<juce::AudioParameterFloat>(
            juce::ParameterID{ "gain", 1 },
            "Gain",
            0.0f,
            1.0f,
            0.5f),
    };
}

PluginProcessor::PluginProcessor()
    : apvts{ *this, nullptr, "Parameters", createParameterLayout() }
    , gain{ apvts.getRawParameterValue("gian") }
{
}
```

```text
warning: no parameter with the ID "gian". Did you mean "gain"? [juce-unknown-parameter-id]
```

### `ValueTree` checks

Various checks for common `ValueTree` misuse.

- [`juce-listener-on-copy`](docs/checks.md#juce-listener-on-copy)
- [`juce-property-name-case`](docs/checks.md#juce-property-name-case)
- [`juce-unbound-cached-value`](docs/checks.md#juce-unbound-cached-value)
- [`juce-unchecked-child-tree`](docs/checks.md#juce-unchecked-child-tree)
- [`juce-undo-manager-consistency`](docs/checks.md#juce-undo-manager-consistency)
- [`juce-valuetree-identity-comparison`](docs/checks.md#juce-valuetree-identity-comparison)

```cpp
class FilterState : private juce::ValueTree::Listener
{
public:
    explicit FilterState(juce::ValueTree& parent)
        : state{ parent.getOrCreateChildWithName("Filter", nullptr) }
    {
        auto bands = state.getChildWithName("Bands");
        bands.addListener(this); // [1]
    }

    void setCutoff(float newCutoff)
    {
        state.setProperty("cutoff", newCutoff, &undoManager);
    }

    void setResonance(float newResonance)
    {
        state.setProperty("resonance", newResonance, nullptr); // [2]
    }

    void addBand()
    {
        state
            .getChildWithName("bands")                             // [3]
            .appendChild(juce::ValueTree{ "Band" }, &undoManager); // [4]
    }

    bool matchesPreset(const juce::XmlElement& preset) const
    {
        return state == juce::ValueTree::fromXml(preset); // [5]
    }

private:
    juce::ValueTree state;
    juce::UndoManager undoManager;
    juce::CachedValue<float> resonance; // [6]
};
```

```text
[1] warning: listener added to a temporary 'juce::ValueTree'. No callbacks will be called [juce-listener-on-copy]
[2] warning: 'setProperty()' is called without an UndoManager, unlike other changes in 'FilterState' that use '&undoManager' [juce-undo-manager-consistency]
[3] warning: 'bands' differs from a previously used identifier, 'Bands', only by case. This is likely a typo [juce-property-name-case]
[4] warning: 'appendChild()' might be called on an invalid tree, as 'getChildWithName()' can return invalid trees. Check 'isValid()' first or use 'getOrCreateChildWithName()' [juce-unchecked-child-tree]
[5] warning: '==' checks that the two ValueTrees use the same underlying object. Use 'isEquivalentTo()' to compare their properties and children [juce-valuetree-identity-comparison]
[6] warning: 'resonance' is never attached to a ValueTree. Call 'resonance.referTo(...) before using it' [juce-unbound-cached-value]
```

### `WebBrowserComponent` checks

Various checks for common `WebBrowserComponent` misuse, including several problems that only show up on Windows.

- [`juce-attachment-order`](docs/checks.md#juce-attachment-order)
- [`juce-duplicate-webview-name`](docs/checks.md#juce-duplicate-webview-name)
- [`juce-hardcoded-resource-provider-root`](docs/checks.md#juce-hardcoded-resource-provider-root)
- [`juce-native-function-completion`](docs/checks.md#juce-native-function-completion)
- [`juce-unregistered-web-relay`](docs/checks.md#juce-unregistered-web-relay)
- [`juce-unrestricted-webview-navigation`](docs/checks.md#juce-unrestricted-webview-navigation)
- [`juce-webview-dev-server-in-release`](docs/checks.md#juce-webview-dev-server-in-release)
- [`juce-webview-event-before-load`](docs/checks.md#juce-webview-event-before-load)
- [`juce-webview-resource-mime-type`](docs/checks.md#juce-webview-resource-mime-type)
- [`juce-webview-windows-options`](docs/checks.md#juce-webview-windows-options)

```cpp
class Editor : public juce::AudioProcessorEditor
{
public:
    Editor(juce::AudioProcessor& p, juce::RangedAudioParameter& gain)
        : juce::AudioProcessorEditor{ p }
        , gainAttachment{ gain, gainRelay }
    {
        addAndMakeVisible(webview);
        webview.goToURL("juce://juce.backend/");             // [1]
        webview.emitEventIfBrowserIsVisible("ready", true); // [2]
    }

private:
    juce::WebBrowserComponent webview{                      // [3]
        juce::WebBrowserComponent::Options{}
            .withNativeIntegrationEnabled()                 // [4]
            .withOptionsFrom(gainRelay)
            .withNativeFunction("save", [](auto& args, auto complete) { // [5]
                save(args[0]);
            })
    };
    juce::WebSliderRelay gainRelay{ "gain" };               // [6]
    juce::WebToggleButtonRelay bypassRelay{ "bypass" };     // [7]
    juce::WebSliderParameterAttachment gainAttachment;
};
```

```text
[1] warning: 'juce://juce.backend' is only the resource provider root on macOS, iOS and Linux. Use 'juce::WebBrowserComponent::getResourceProviderRoot()' instead [juce-hardcoded-resource-provider-root]
[2] warning: the page won't have loaded yet, so the frontend can't receive this event. Use 'withInitialisationData()' to pass initial state to the page [juce-webview-event-before-load]
[3] warning: any page 'juce::WebBrowserComponent' navigates to can use its native integration. Override 'pageAboutToLoad()' to only allow your own pages [juce-unrestricted-webview-navigation]
[4] warning: 'withNativeIntegrationEnabled()' only works on Windows with the WebView2 backend. Add '.withBackend(juce::WebBrowserComponent::Options::Backend::webview2)' [juce-webview-windows-options]
[5] warning: 'complete' is never called, so the promise returned to JavaScript never resolves [juce-native-function-completion]
[6] warning: 'gainRelay' is declared after 'webview' which it's registered with. Declare 'gainRelay' before 'webview' [juce-attachment-order]
[7] warning: 'bypassRelay' is never registered with a WebBrowserComponent using 'withOptionsFrom()' [juce-unregistered-web-relay]
```

### Accessibility checks

Various checks for controls and custom components that screen readers can't describe or use.

- [`juce-missing-accessibility-handler`](docs/checks.md#juce-missing-accessibility-handler)
- [`juce-untitled-control`](docs/checks.md#juce-untitled-control)

```cpp
class XYPad : public juce::Component // [1]
{
public:
    void mouseDrag(const juce::MouseEvent& event) override;
};

class Editor : public juce::Component
{
public:
    Editor()
    {
        addAndMakeVisible(gainSlider);
        addAndMakeVisible(bypassButton);
        addAndMakeVisible(xyPad);
    }

private:
    juce::Slider gainSlider{ "Gain" }; // [2]
    juce::ToggleButton bypassButton;   // [3]
    XYPad xyPad;
};
```

```text
[1] warning: 'XYPad' handles mouse input but doesn't override 'createAccessibilityHandler()', so screen readers can't tell what it is or interact with it [juce-missing-accessibility-handler]
[2] warning: 'gainSlider' is never given an accessible title. Call 'setTitle()' so screen readers can announce it [juce-untitled-control]
[3] warning: 'bypassButton' is never given an accessible title. Call 'setTitle()' or 'setButtonText()' so screen readers can announce it [juce-untitled-control]
```

## Installing

The plugin requires Clang-Tidy 23, which is packaged with LLVM 23, so be sure to install it with

```bash
brew install llvm@23
```

_(Only macOS is supported as Clang-Tidy can't load plugins on Windows)._

Then download the latest version from [GitHub Releases](https://github.com/ImJimmi/JuceTidy/releases) and extract `JuceTidy.so` somewhere convenient.

If macOS refuses to load the downloaded plugin, remove its quarantine attribute:

```bash
xattr -d com.apple.quarantine /path/to/JuceTidy.so
```

### Building from source

The plugin only works with the major version of Clang-Tidy it was built against, so if the prebuilt release doesn't match your Clang-Tidy version or architecture, build it yourself with

```bash
cmake \
  -B build \
  -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH="$(brew --prefix llvm@23)"

cmake --build build
```

The CMake config includes installation rules so you can use `cmake --install` to copy the plugin to a system folder if you so wish.

```bash
cmake --install build
```

By default this installs the plugin to `/usr/local/lib/JuceTidy.so`, which may require `sudo`. Use `--prefix` to install it somewhere else instead:

```bash
cmake --install build --prefix ~/.local
```

## Usage

Load the plugin (`JuceTidy.so`) with `--load` and enable the checks you want:

```bash
clang-tidy \
  --load=/path/to/plugins/JuceTidy.so \
  --checks='-*,juce-*' \
  -p path/to/your/build \
  MyJuceCode.cpp
```

See [Suppressing Undesired Diagnostics](https://clang.llvm.org/extra/clang-tidy/#suppressing-undesired-diagnostics) for how to suppress any of the JUCE checks you don't want to enforce.

Note that Clang-Tidy runs per-source file and so can't catch issues that span multiple sources. These checks therefore aren't guaranteed to catch every case, so you should still review your code carefully.
